# 予定・タスク・日次活動ログ管理ツール(GAS Webアプリ)

大学・部活・筋トレなどの日々の活動記録と、短期/中長期のタスク管理、
Googleカレンダーの予定表示・登録をひとつの画面でまとめて行える
Google Apps Script製のWebアプリです。

## できること

### 📅 カレンダービュー(メイン画面)
- 月表示のカレンダー。前月/次月への移動、「今日」ボタンあり
- 各日付に、その日の記録に応じた色マークを表示
  - 大学に行った日(いずれかの時限に出席): **青**
  - 部活があった日: **緑**
  - 筋トレした日: **オレンジ**
  - 自分で追加したカテゴリ(バイト・読書など): 好きな色
  - 複数該当する日はマークが並んで表示されます
- Googleカレンダーに登録済みの予定もセルに表示されます
- 日付をクリックすると日次入力パネル(モーダル)が開きます

### ✏️ 日次入力パネル
- **大学**: 1〜5限それぞれに「科目名 / 出席チェック / メモ」を入力
  - 設定画面で時間割を登録しておくと科目名が自動でプリセットされます
- **部活**: 行った/行っていないチェック + 自由記述メモ
- **筋トレ**: 実施チェック + 種目・時間などの自由記述
- **追加カテゴリ**: 設定画面で追加したカテゴリもチェック+メモで記録可能
- **その他メモ / 短期タスク進捗 / 中長期タスク進捗**: 自由記述
- **Googleカレンダーへの予定登録**: タイトルと時刻を入れてその日の予定を追加
  (開始時刻を空欄にすると終日予定)
- 保存するとスプレッドシートの該当日の行が更新(なければ新規作成)されます

### ✅ タスク管理
- 短期タスクと中長期タスクを分けて一覧表示
- タスク名・期限・優先度(高/中/低)・ステータス(未着手/進行中/完了)を管理
- 一覧上でステータスを直接変更可能。期限切れは赤字で警告表示
- 中長期タスクは進捗率(%)をスライダーで入力でき、進捗バーで表示されます

### ⚙️ 設定
- **記録カテゴリ**: マークに使うカテゴリの追加・削除・色変更
  (大学/部活/筋トレはデフォルトとして固定。色のみ変更可能)
- **時間割**: 曜日×1〜5限の科目マスタ。日次入力パネルに自動反映

## データの保存先(スプレッドシート)

初回アクセス時に以下の4シートが自動生成されます。

| シート | 列 |
| --- | --- |
| 日次記録 | 日付 / 大学 / 部活 / 部活メモ / 筋トレ / 筋トレ詳細 / メモ / 短期タスク進捗 / 中長期タスク進捗 / カスタム |
| タスク | タスクID / タスク名 / 種別(短期・中長期) / 期限 / 優先度 / ステータス / 進捗率 |
| カテゴリ | カテゴリID / 名前 / 色 / 固定 |
| 時間割 | 曜日 / 1限 / 2限 / 3限 / 4限 / 5限 |

※「大学」列は1〜5限分の科目・出席・メモをJSON文字列で保持します。
※「カスタム」列は追加カテゴリの記録をJSON文字列で保持します。

## セットアップ手順(5分程度)

### 1. スプレッドシートを作る
1. [https://sheets.google.com](https://sheets.google.com) で空白のスプレッドシートを新規作成
   (名前は「活動ログ」など何でもOK)

### 2. スクリプトエディタを開いてコードを貼る
1. メニューの **拡張機能 → Apps Script** をクリック
2. 最初からある `コード.gs` の中身を全部消し、`Code.gs` の内容を貼り付け
3. **＋(ファイルを追加)→ HTML** で以下の3ファイルを作成し、それぞれ内容を貼り付け
   - `Index`(→ `Index.html` の内容)
   - `Stylesheet`(→ `Stylesheet.html` の内容)
   - `JavaScript`(→ `JavaScript.html` の内容)
   ※ファイル名は拡張子なしで上記の通りにしてください
4. 保存(Ctrl+S / ⌘+S)

### 3. 初回セットアップ(権限の承認)
1. エディタ上部の関数選択で `setup` を選び **実行**
2. 「承認が必要です」と出たら、自分のGoogleアカウントで
   スプレッドシートとカレンダーへのアクセスを許可
   (「このアプリは確認されていません」と出た場合は
   「詳細 → (プロジェクト名)に移動」から進めます)
3. 実行が完了すると、シート構成が自動生成されます

### 4. Webアプリとしてデプロイ
1. 右上の **デプロイ → 新しいデプロイ** をクリック
2. 種類の選択(歯車アイコン)で **ウェブアプリ** を選択
3. 次のように設定して **デプロイ**
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **自分のみ**
4. 表示されたURLを開けば利用開始です(スマホのブラウザからもOK)

### コードを修正したとき
**デプロイ → デプロイを管理 → (鉛筆アイコン) → バージョン: 新バージョン → デプロイ**
で反映されます(URLは変わりません)。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | サーバー側処理(シート読み書き・カレンダー連携・セットアップ) |
| `Index.html` | 画面のHTML(カレンダー/タスク/設定の3ビュー+モーダル) |
| `Stylesheet.html` | CSS |
| `JavaScript.html` | クライアント側JS(描画・入力収集・google.script.run呼び出し) |
| `appsscript.json` | マニフェスト(タイムゾーン等。エディタの「プロジェクトの設定」から表示可能) |

## 主なサーバー側関数

| 関数 | 内容 |
| --- | --- |
| `doGet()` | HTML画面を返す |
| `setup()` | 初回セットアップ(手動実行用・権限承認) |
| `setupSheets()` | 必要なシート・見出し行が無ければ自動生成 |
| `getMonthData(year, month)` | 指定月の全日次記録マーク+カレンダー予定を取得 |
| `getDayData(date)` | 指定日の詳細データ取得(無ければ時間割から初期値を生成) |
| `saveDayData(date, data)` | 指定日のデータを保存・更新 |
| `getTasks()` / `saveTask(task)` / `deleteTask(taskId)` | タスクの取得・追加/更新・削除 |
| `getCategories()` / `saveCategory(c)` / `deleteCategory(id)` | 記録カテゴリの管理 |
| `getTimetable()` / `saveTimetable(tt)` | 時間割マスタの取得・保存 |
| `addCalendarEvent(date, title, start, end)` | Googleカレンダーへ予定登録 |

## 補足

- タイムゾーンは `Asia/Tokyo` 前提です(`appsscript.json`)。
- カレンダー連携はデフォルトカレンダー(自分のメインカレンダー)を対象にしています。
- スプレッドシートを直接編集しても動きますが、日付列は `yyyy-MM-dd` の
  文字列形式を保ってください。
- スタンドアロンスクリプトとして作成した場合は、初回実行時に
  「予定・タスク管理データ」という専用スプレッドシートが自動作成されます。
