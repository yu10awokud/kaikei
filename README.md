# 収入管理ツール（GAS Webアプリ）

家庭教師（生徒A/B）の勤務記録・収入の自動計算と、スイング投資の損益を
ひとつの画面でまとめて管理するためのGoogle Apps Script製アプリです。

## できること

- **トップ画面**：今月の収入・先月の収入・前月比（±）を表示。家庭教師／スイング投資の内訳も表示。
- **カレンダー**：日付をタップして「どの生徒を何時間教えたか」を記録。時給（マスタ）から金額を自動計算。
- **スイング投資**：日付ごとに損益（プラス／マイナス）を記録。月合計を集計。
- **設定（マスタ）**：生徒の名前・時給を後からいつでも変更可能（初期値 A=4200円 / B=3500円）。

データはこのスクリプトに紐づく**Googleスプレッドシート**に保存されます
（`設定` / `家庭教師` / `スイング投資` の3シートが自動生成されます）。

## ❓「どこにコードを打ち込めばいいの？」 セットアップ手順

GASのコードは「スプレッドシートに紐づいたスクリプトエディタ」に貼り付けます。
以下のとおり進めてください（5分くらいで終わります）。

### 1. スプレッドシートを作る
1. ブラウザで [https://sheets.google.com](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」を新規作成（名前は「収入管理」など何でもOK）

### 2. スクリプトエディタを開く
1. メニューの **拡張機能 → Apps Script** をクリック
2. 新しいタブで「スクリプトエディタ」が開きます

### 3. コードを貼り付ける
スクリプトエディタの左側にファイル一覧があります。次の5ファイルを作って、
このリポジトリの中身をそのままコピペします。

| エディタでのファイル名 | このリポジトリのファイル | 作り方 |
|---|---|---|
| `Code.gs` | `Code.gs` | 最初からある `コード.gs` の中身を全部消して貼り付け（名前は `Code` のままでOK） |
| `Index.html` | `Index.html` | 「＋」→ HTML → 名前を `Index` にして貼り付け |
| `Stylesheet.html` | `Stylesheet.html` | 「＋」→ HTML → 名前を `Stylesheet` にして貼り付け |
| `JavaScript.html` | `JavaScript.html` | 「＋」→ HTML → 名前を `JavaScript` にして貼り付け |
| `appsscript.json`（マニフェスト） | `appsscript.json` | ⚙️設定 →「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック → 中身を貼り付け |

> ⚠️ HTMLファイルを作るとき、エディタは自動で `.html` を付けます。
> 名前欄には `Index` `Stylesheet` `JavaScript` のように**拡張子なし**で入力してください。

### 4. 保存して動作確認
1. 💾（保存）を押す
2. 関数選択のプルダウンで `init` を選び **▶実行**
   - 初回は「承認が必要です」と出るので、自分のGoogleアカウントで許可してください
   - これでスプレッドシートに3つのシートが自動で作られます

### 5. Webアプリとして公開（アプリ化）
1. 右上の **デプロイ → 新しいデプロイ**
2. 種類の選択（⚙️）で **ウェブアプリ** を選ぶ
3. 設定：
   - 説明：任意（例「収入管理 v1」）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
4. **デプロイ** を押すと **ウェブアプリのURL** が発行されます

→ この**URLをスマホやPCのブラウザでブックマーク**すれば、アプリのように使えます。
　スマホなら「ホーム画面に追加」しておくとアプリアイコンとして起動できます。

### コードを修正したとき
コードを直したら、**デプロイ → デプロイを管理 → ✏️編集 → バージョン「新バージョン」→ デプロイ**
で更新します（URLは変わりません）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー側。スプレッドシートの読み書き・集計・収入計算 |
| `Index.html` | 画面の構造（トップ／カレンダー／スイング／設定タブ） |
| `Stylesheet.html` | デザイン（CSS） |
| `JavaScript.html` | 画面の動き（クライアント側JS） |
| `appsscript.json` | GASの設定（タイムゾーン・Webアプリ設定） |

## 収入の計算ルール

- 家庭教師の金額 = `時給（マスタ） × 時間`（保存時にサーバー側で計算）
- 月の収入 = `家庭教師の合計` + `スイング投資の損益合計`
- 前月比（±） = `今月の収入` − `先月の収入`
