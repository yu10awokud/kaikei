# 水泳練習記録アプリ（GAS Webアプリ）

水泳の練習記録を、**スマホのブラウザから練習直後にその場で入力**することを
メインユースケースとしたGoogle Apps Script製アプリです。
データはこのスクリプトに紐づく**Googleスプレッドシート**に保存されます。

## できること（7画面）

- **① 記録入力**（デフォルト画面）：日付・総距離・メモに加えて、**形式（TT／Short／Middle）**を
  選んでタイム記録を追加。
  - **TT**（タイムトライアル）：種目・距離・タイムを1本ずつ記録。
  - **Short／Middle**：種目 × 距離 × 本数 × セット を指定し、`50×4×2` なら8本分の入力欄を
    一括生成してまとめて記録。
- **② 履歴一覧**：練習を新しい順に表示。種目・**日付**でフィルタ、練習ごと・タイム単体での編集／削除。
- **③ 分析**：2モードを切替。
  - **タイム推移**：種目・距離・水路タイプ（長水路／短水路／両方）・期間で絞り込んだタイムを折れ線表示。
    **縦軸は上ほど速い**（Y軸反転）。**練習(TT)は青丸、試合記録は赤丸**で重ねて表示。
  - **総距離推移**：期間内の日ごとの総距離(m)を折れ線表示。
  - 期間は 週間／月間／3か月／全期間 を切替（Chart.js）。
- **④ 試合記録**：大会名・日付・水路タイプ・**種別（正式／引継ぎ）**・種目・距離・タイムを記録。
  分析の赤丸に反映される。
- **⑤ ベスト**：試合記録から **種別 × 種目 × 距離** ごとの最速タイムを自動集計して表形式で表示。
  - **正式**：Fr / Ba / Br / Fly / IM。距離は 50 / 100 / 200（**400・800 は Fr のみ**）。
  - **引継ぎ**：Fr / Br / Fly（Ba・IM は存在しない）。距離は Fr=50 / 100 / 200、Br・Fly=50 / 100。
  - 水路タイプ（両方／長水路／短水路）で絞り込み可能。対象外のマスは斜線で表示。
- **⑥ 種目マスタ**：種目の追加・アーカイブ（削除ではなくアーカイブ方式。過去データは保持）。
- **⑦ プールマスタ**：プール名＋水路タイプ（長水路／短水路）の追加・アーカイブ。

> 分析グラフのタイム推移には、練習は **TT の記録のみ** 反映されます（Short／Middle は集計対象外）。

### タイム入力の形式
- `1:19.50` → 79.50秒（分:秒.ミリ秒）
- `30.20` → 30.20秒（1分未満は秒のみでもOK）

保存時にサーバー側で秒数に変換して保存し、表示時に読みやすい形式へ戻します。

### データ構造（スプレッドシート5シート）

| シート | 列 |
|---|---|
| `PracticeLog`（練習ログ） | ID / 日付 / 総距離 / メモ |
| `TimeRecord`（タイム記録） | ID / 練習ログID / 日付 / 種目 / 距離 / タイム(秒) / プール / 形式 |
| `EventMaster`（種目マスタ） | ID / 種目名 / 状態（有効・アーカイブ） |
| `PoolMaster`（プールマスタ） | ID / プール名 / 水路タイプ / 状態（有効・アーカイブ） |
| `MeetRecord`（試合記録） | ID / 大会名 / 日付 / 水路タイプ / 種目 / 距離 / タイム(秒) / 種別（正式・引継ぎ） |

初回アクセス時に5シートが自動生成されます（種目は Fr / Ba / Br / Fly / IM を初期投入）。

## セットアップ手順

GASのコードは「スプレッドシートに紐づいたスクリプトエディタ」に貼り付けます。

### 1. スプレッドシートを作る
1. [https://sheets.google.com](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」を新規作成（名前は「水泳記録」など何でもOK）

### 2. スクリプトエディタを開く
1. メニューの **拡張機能 → Apps Script** をクリック

### 3. コードを貼り付ける
次の5ファイルを作り、このリポジトリの中身をそのままコピペします。

| エディタでのファイル名 | このリポジトリのファイル | 作り方 |
|---|---|---|
| `Code.gs` | `Code.gs` | 最初からある `コード.gs` の中身を全部消して貼り付け |
| `Index.html` | `Index.html` | 「＋」→ HTML → 名前を `Index` にして貼り付け |
| `Stylesheet.html` | `Stylesheet.html` | 「＋」→ HTML → 名前を `Stylesheet` にして貼り付け |
| `JavaScript.html` | `JavaScript.html` | 「＋」→ HTML → 名前を `JavaScript` にして貼り付け |
| `appsscript.json` | `appsscript.json` | ⚙️設定 →「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック → 貼り付け |

> ⚠️ HTMLファイルの名前欄は `Index` `Stylesheet` `JavaScript` のように**拡張子なし**で入力してください。

### 4. 保存して動作確認
1. 💾（保存）を押す
2. 関数選択で `init` を選び **▶実行** → 初回は承認を許可
   - これでスプレッドシートに5シートが自動生成されます

### 5. Webアプリとして公開
1. 右上の **デプロイ → 新しいデプロイ**
2. 種類の選択（⚙️）で **ウェブアプリ**
3. 設定：次のユーザーとして実行＝**自分** / アクセスできるユーザー＝**自分のみ**
4. **デプロイ** で **ウェブアプリのURL** が発行されます

→ このURLをスマホでブックマーク／「ホーム画面に追加」すればアプリのように使えます。

### コードを修正したとき
**デプロイ → デプロイを管理 → ✏️編集 → バージョン「新バージョン」→ デプロイ**
で更新します（URLは変わりません）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー側。シート自動作成・マスタ管理・練習記録CRUD・分析集計・タイム変換 |
| `Index.html` | 7画面のHTML構造（ハンバーガーメニュー + SPA切替） |
| `Stylesheet.html` | デザイン（CSS、青系レスポンシブ） |
| `JavaScript.html` | クライアント側JS（画面制御・通信・Chart.js描画） |
| `appsscript.json` | GASの設定（タイムゾーン Asia/Tokyo・Webアプリ設定） |

## 主要なサーバー関数

| 関数 | 役割 |
|---|---|
| `getMasters()` | 有効な種目・プールをまとめて取得（初期化用） |
| `addEvent` / `archiveEvent` | 種目マスタの追加・アーカイブ |
| `addPool` / `archivePool` | プールマスタの追加・アーカイブ |
| `savePractice(payload)` | 練習ログ＋タイム記録の新規保存・更新（タイムを秒数へ変換） |
| `getHistory(eventFilter)` | 履歴一覧の取得（種目フィルタ対応） |
| `deletePractice` / `deleteTimeRecord` | 練習ごと削除・タイム単体削除 |
| `getAnalysisData(event, distance, lane, period)` | 分析グラフ用に練習(TT)と試合のタイム点列を取得 |
| `getEventDistances(event)` | 分析の距離プルダウン用に、その種目で記録のある距離一覧を取得 |
| `getDistanceTrend(period)` | 分析グラフ用に日ごとの総距離推移を取得 |
| `getMeetRecords` / `saveMeetRecord` / `deleteMeetRecord` | 試合記録の取得・保存・削除 |
| `getBestTimes(lane)` | 試合記録から種別×種目×距離ごとの最速タイムを集計 |
