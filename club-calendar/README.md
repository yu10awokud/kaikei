# 部活スケジュール共有カレンダー（GAS Webアプリ）

部活動の予定を月間カレンダーで管理・共有するための Google Apps Script(GAS) 製 Web アプリです。
URL を知っている部員が閲覧・編集できます（認証なしのMVP構成）。

- 月間カレンダー（日曜始まり／前月・翌月移動。「8 August … 2026」ヘッダー）
- 予定の追加・編集・削除（色指定・単発／毎週繰り返し）
- マスは **予定色で全面塗りつぶし**（練習＝場所＋時間、イベント＝タイトルを中央に）
- 合宿・大会などの複数日イベントは、**期間のマスを同じ色で塗って連結**（タイトルは中央の日に表示）
- 練習予定は **場所（中央）／ブログ担当（右上・赤）／時間（中央下）** のレイアウト
- 曜日見出しは 日＝赤・土＝青、日付色も 日/祝＝赤・土＝青（祝日は Google の日本の祝日カレンダーを利用）
- 前月末・翌月頭の日付は薄いグレーで表示（常に6週）
- スマホ対応のレスポンシブ表示・入力はモーダル
- 「JPG出力」ボタン（画面と同じ**横長カレンダーを1枚のJPG画像**で書き出し。そのままLINE等で共有できます）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | GAS本体。スプレッドシートへの予定の保存・取得・削除（CRUD）、祝日取得 |
| `Index.html` | 画面の骨組み（カレンダー枠・モーダル） |
| `Stylesheet.html` | 見た目（CSS）。`<?!= include('Stylesheet') ?>` で読み込み |
| `JavaScript.html` | 画面ロジック（描画・展開・モーダル）。`google.script.run` でサーバーと通信 |
| `appsscript.json` | マニフェスト（タイムゾーン・権限スコープ・公開設定） |

## セットアップ手順

### 1. スプレッドシートを用意する
1. [Googleスプレッドシート](https://sheets.new) を新規作成します（名前は任意、例：「部活カレンダー」）。
2. このスプレッドシートを保存先にします。**シートやカラムは手で作る必要はありません**（初回アクセス時に「予定」シートが自動生成されます）。

### 2. Apps Script プロジェクトを作る
おすすめは **スプレッドシートに紐づける方法**（`SPREADSHEET_ID` の設定が不要）です。

1. 上記スプレッドシートで **拡張機能 → Apps Script** を開きます。
2. 生成された `コード.gs` の中身を、本リポジトリの `Code.gs` で置き換えます。
3. 左の「＋」から **HTMLファイル** を3つ作り、それぞれ
   `Index` / `Stylesheet` / `JavaScript` という名前にして、対応するファイルの中身を貼り付けます。
   （ファイル名は拡張子 `.html` を除いた名前で作成します）
4. `appsscript.json` を使う場合は、プロジェクト設定で「マニフェストファイルをエディタで表示」を有効にし、内容を貼り付けます。

> スタンドアロン（スプレッドシートに紐づけない）で作る場合は、`Code.gs` 冒頭の
> `SPREADSHEET_ID = ''` を、保存先スプレッドシートのID（URLの `/d/ここ/edit` 部分）に差し替えてください。

### 3. デプロイ（Webアプリとして公開）
1. Apps Script エディタ右上の **デプロイ → 新しいデプロイ** をクリック。
2. 種類は **ウェブアプリ** を選択。
3. 設定：
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**（部員に共有する場合）
4. **デプロイ** を押すと初回は権限承認を求められるので許可します
   （スプレッドシート＋祝日カレンダーの読み取り権限）。
5. 表示された **ウェブアプリのURL** を部員に共有すれば完成です。

> コードを直したら、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン＝新バージョン → デプロイ** で反映されます。

## 毎週予定の「この日だけ変更」（例：ブログ担当だけ差し替え）

毎週の練習は「毎週」で一度だけ登録しておき、**ブログ担当だけをその週ごとに変える**、という使い方に対応しています。

- 毎週予定のマスをクリックすると、モーダル上部に **「この日だけ / 毎週すべて」** の切り替えが出ます。
  - **この日だけ**（初期選択）：その日のブログ担当・場所・時間・色だけを変更。**他の週はそのまま**残ります。
  - **毎週すべて**：予定そのもの（親）を変更。全ての回に反映されます。
- 「この日だけ」で変更した日には **「初期設定に戻す」** ボタンが出て、いつでも毎週の元設定に戻せます。
- 「この日だけ」で **削除** すると、その週だけ非表示（他の週は残る）になります。

この「この日だけ」の変更は、専用の **`例外` シート**（`masterId`／`date`／各項目／`hidden`）に自動保存されます。

## データの持ち方（「予定」シート）

初回アクセス時に自動生成されるカラムは以下です。

| 列 | 内容 |
| --- | --- |
| `id` | 一意なID（自動採番） |
| `title` | 予定名（合宿・大会など、イベント用） |
| `startDate` | 開始日（`yyyy-MM-dd`） |
| `endDate` | 終了日（複数日イベントで使用。単日なら開始日と同じ） |
| `color` | 背景色（カラーコード） |
| `type` | `event`（イベント）/ `practice`（練習） |
| `place` | 場所（練習用） |
| `blogUser` | ブログ担当（練習用） |
| `time` | 時間（練習用。例：7:20〜9:30） |
| `recurrence` | `none`（単発）/ `weekly`（毎週） |
| `weekday` | 毎週予定の曜日（0=日 … 6=土。開始日から自動設定） |

## 使い方

- **予定を追加**：日付マスの空いている所をクリック → モーダルで入力 → 保存
  - 「練習／イベント」を切り替え（練習＝場所・担当・時間、イベント＝タイトル＋期間）
  - **イベントの見え方**：単発（1日）のイベントは練習と同じくマス全面に色付きで表示。合宿・大会など**複数日**は期間のマスを同じ色で塗って連結（タイトルは中央の日に表示）
  - **2部練の時間**：時間欄で改行すると2行で表示できます（例：1行目 `9:45〜11:45`／2行目 `14:45〜16:45`）
  - 「単発／毎週」を切り替え（毎週は開始日の曜日で、以降ずっと表示）
  - 色はプリセット丸ボタン or カラーピッカーで指定（マス全面が薄い塗り＋文字は濃い同系色）
- **編集・削除**：カレンダー上の色付きマスをクリック（そのまま編集モーダルが開きます）
- **月移動**：ヘッダーの `‹` `›`、「今日」で当月へ
- **JPG出力**：「JPG出力」ボタンを押すだけ
  - **iPad・スマホ**：端末の共有シートが開くので「**画像を保存**」で写真アプリへ保存（そのままLINE等へ共有も可）
  - 共有シートが使えない環境ではプレビューが出るので、画像を**長押し →「"写真"に保存」**、またはPCなら「端末に保存」ボタン
  - ファイル名は `部活カレンダー_2026-09.jpg` のように自動で付きます
  - 画像は **2400×1784px の横長**（画面と同じ比率）です

## 今後の改修ポイント（どこを触れば何が変わるか）

- **保存先を変えたい** → `Code.gs` 冒頭の `SPREADSHEET_ID` / `SHEET_NAME`
- **色プリセットを増減したい** → `Code.gs` と `JavaScript.html` の `PRESET_COLORS`（両方そろえる）
- **マスの塗りの濃さ・文字色の濃さ** → `JavaScript.html` の `hexToRgba(color, 0.16)`（塗り）／`darken()`（文字）
- **マス内の配置（場所・時間・タイトル）** → `Stylesheet.html` の `.cell-body` / `.cb-place` / `.cb-time` / `.cb-title`、右上ノートは `.day-note`
- **曜日見出しや日付色（土=青／日・祝=赤）、罫線、全体トーン** → `Stylesheet.html` の `:root` 変数と `.weekdays`
- **ヘッダー（8 August / 2026）の見た目** → `Stylesheet.html` の `.cal-titlebar`、月名は `JavaScript.html` の `MONTH_NAMES`
- **予定の見た目・並び** → `JavaScript.html` の `render()` と `buildCellBody()`
- **JPG出力の大きさ・文字サイズ** → `JavaScript.html` の `JPG` 定数（`W`＝横幅／`CELL_H`＝マスの高さ／`QUALITY`＝画質）
- **繰り返しルールの追加（隔週・毎月など）** → `Code.gs` の `saveSchedule` と `JavaScript.html` の `occursOn` / `render()` の展開部
- **「この日だけ変更」の仕組み** → `Code.gs` の `例外`シート＋`saveOverride`/`deleteOverride`、`JavaScript.html` の `effective()`（値の重ね合わせ）
- **データが増えて重い** → `Code.gs` の `getSchedules()` を「表示中の年月＋前後だけ返す」形に絞ると軽くなります

## 制限事項（MVPのため）

- 認証なし（URLを知っていれば誰でも編集可）。将来的に `appsscript.json` の `access` を絞る等で対応。
- JPG出力は Canvas に直接描画しています（外部ライブラリ不要・iPad の Safari でも動作）。
  - 保存は Web Share API（共有シート）を優先し、使えない環境ではプレビュー＋長押し保存にフォールバックします。
  - 出力サイズや文字サイズは `JavaScript.html` の `JPG` 定数（`W` / `CELL_H` など）で調整できます。
  - 画面と同じ内容になるよう、描画データは `buildMonthCells()` を画面・画像で共用しています。
