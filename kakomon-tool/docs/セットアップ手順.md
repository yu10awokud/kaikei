# はじめてのセットアップ手順（Windows・初心者向け）

GAS（Google Apps Script）しか触ったことがない方でも進められるよう、
**ゼロから順番に**説明します。専門用語は最小限にします。

## この作業のイメージ

GAS はブラウザだけで動きますが、このツールは「自分のPCに材料を入れて、
**ターミナル**（コマンドを打つ黒い画面）から実行する」タイプです。
用意する材料は3つだけ:

1. **Python** … ツール本体（.pyファイル）を動かすための言語
2. **TeX Live** … きれいなPDFに組み上げるためのソフト（`lualatex`）
3. **APIキー** … Claude に問題を読ませ・解かせるための鍵（有料）

チェックリスト形式で進めます。各ステップの最後に「✅ 確認」があるので、
その通りに表示されたら次へ進んでください。

---

## ステップ0. ツール一式を自分のPCに置く

コードは GitHub 上にあります。まだお使いのPCに無ければ、ZIPで落とすのが簡単です。

1. ブラウザで自分のリポジトリ（`yu10awokud/kaikei`）を開く
2. 緑色の **「Code」** ボタン → **「Download ZIP」**
3. ダウンロードした ZIP を右クリック →「すべて展開」
4. 展開先の中に **`kakomon-tool`** というフォルダがあります。これが本体です。
   分かりやすい場所（例: `ドキュメント` の中）に置いてください。

> ブランチが `claude/modest-wozniak-w6f94u` の場合は、GitHub の画面左上の
> ブランチ切替（枝アイコン）でそのブランチを選んでから Download ZIP してください。

✅ 確認: `kakomon-tool` フォルダの中に `src`, `templates`, `config.py`,
`requirements.txt` などがある。

---

## ステップ1. ターミナル（PowerShell）を開く

Windows標準の「PowerShell」を使います。**このフォルダの場所で**開くのがコツです。

1. エクスプローラーで `kakomon-tool` フォルダを開く
2. 何もないところで **Shift を押しながら右クリック**
3. 「**PowerShell ウィンドウをここで開く**」または「**ターミナルで開く**」を選ぶ
   - 無ければ: フォルダ上部のアドレスバーに `powershell` と打って Enter でもOK

黒い（または青い）画面が出て、先頭に今のフォルダのパスが表示されていれば成功です。
以降のコマンドは、すべてこの画面に打ち込んで Enter で実行します。

✅ 確認: 画面の行頭が `...\kakomon-tool>` のようになっている。

---

## ステップ2. Python を入れる

1. ブラウザで **https://www.python.org/downloads/** を開く
2. 「Download Python 3.x」ボタンでインストーラーをダウンロード
3. インストーラーを実行。**最初の画面で必ず
   「Add python.exe to PATH」にチェックを入れてから** 「Install Now」

> ⚠ この「Add ... to PATH」のチェックを忘れると、後で `python` コマンドが
> 「見つかりません」になります。忘れたら入れ直してください。

インストール後、**PowerShell を一度閉じて、ステップ1でもう一度開き直します**
（PATH を反映させるため）。そして確認:

```powershell
python --version
```

✅ 確認: `Python 3.11.x`（数字は前後してOK）と表示される。

---

## ステップ3. TeX Live を入れる（PDF組版ソフト）

これが一番時間のかかる作業です（**ダウンロード＋インストールで数時間**かかることも）。
時間に余裕のあるときに始めてください。

1. ブラウザで **https://tug.org/texlive/windows.html** を開く
2. 「install-tl-windows.exe」をダウンロードして実行
3. 基本はそのまま進めてインストール（フルインストール推奨。容量は数GB）

インストール後、**PowerShell を開き直して**確認:

```powershell
lualatex --version
```

✅ 確認: `This is LuaHBTeX, Version ...` のように表示される。
（「見つかりません」の場合は PC を再起動してから再確認）

### フォントの確認（Noto Serif CJK JP）

このツールは日本語フォントを **Noto Serif CJK JP** に固定しています。
入っているか確認します:

1. Windows の「設定」→「個人用設定」→「フォント」
2. 検索欄に `Noto Serif` と入力
3. **「Noto Serif CJK JP」** が出てくればOK

もし無ければインストールします:

1. **https://github.com/notofonts/noto-cjk/tree/main/Serif** を開く
2. `NotoSerifCJKjp-Regular.otf`（と Bold）などをダウンロード
3. ダウンロードした `.otf` を右クリック →「**すべてのユーザーに対してインストール**」

✅ 確認: 設定のフォント一覧に「Noto Serif CJK JP」が表示される。

## ステップ4. ツール専用の置き場（仮想環境）を作る

Python では、プロジェクトごとに専用のパッケージ置き場（**仮想環境**）を作るのが
定番です。GAS には無い概念ですが、「このツール専用の小部屋を作る」くらいの理解でOK。

PowerShell が `kakomon-tool` フォルダにいることを確認して、順に実行します。

```powershell
python -m venv .venv
```

（少し待つと `.venv` フォルダができます。これが小部屋です）

次に、その小部屋を「使う状態」にします（**有効化**）:

```powershell
.\.venv\Scripts\Activate.ps1
```

✅ 確認: 行頭に **`(.venv)`** が付く（例: `(.venv) ...\kakomon-tool>`）。

> ⚠ ここで **「このシステムではスクリプトの実行が無効になっています」** という
> 赤いエラーが出ることがあります。よくあるWindowsのセキュリティなのでOKです。
> 次の1行を実行して `Y` を押し、もう一度 `Activate.ps1` を実行してください:
>
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

> 💡 次回以降このツールを使うときも、毎回このフォルダで
> `.\.venv\Scripts\Activate.ps1` を実行して `(.venv)` を付けてから使います。

---

## ステップ5. 必要なパッケージを入れる

`(.venv)` が付いた状態で、次を実行します（ツールが使うライブラリを取り込みます）:

```powershell
pip install -r requirements.txt
```

しばらく通信します。`anthropic`, `PyMuPDF`, `Jinja2` などが入ります。

✅ 確認: 最後に `Successfully installed anthropic-... PyMuPDF-... Jinja2-...`
のように出て、赤いエラーで止まっていない。

---

## ステップ6. APIキーを用意して設定する

Claude に問題を読ませ・解かせるための鍵です。**利用に応じて課金**されます
（このツールは1問ずつ課金を抑える作りですが、費用はご自身で確認を）。

1. ブラウザで **https://console.anthropic.com/** を開き、ログイン
2. 支払い方法を登録（有料。少額のクレジットからでOK）
3. 「API Keys」でキーを新規作成。`sk-ant-...` という文字列をコピー

GAS の「スクリプトプロパティ」に鍵を置くのと同じ発想で、コードには書かず
**環境変数**に入れます。PowerShell で（`sk-ant-...` を自分のキーに置き換えて）:

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-ここに自分のキー"
```

> ⚠ この方法は「今開いているPowerShellの間だけ」有効です。ウィンドウを閉じると
> 消えるので、次回また同じコマンドを打ちます。
>
> 毎回打つのが面倒なら、次を1回だけ実行すると恒久的に保存されます（実行後は
> **PowerShellを開き直す**と有効になります）:
>
> ```powershell
> setx ANTHROPIC_API_KEY "sk-ant-ここに自分のキー"
> ```

✅ 確認（設定できたかの確認。キーの一部が表示されればOK）:

```powershell
echo $env:ANTHROPIC_API_KEY
```

## ステップ7. まずは無料で組版テスト（モックモード）

**いきなり本番（課金）に行かず**、まず自分のPCでPDFが作れるかを無料で確認します。
API を一切使わず、サンプル問題からPDFを組みます。

`(.venv)` が付いた状態で:

```powershell
python src\run.py --mock
```

処理が進み、最後に `完成PDF: ...\output\mondaishu.pdf` と出れば成功です。
`kakomon-tool\output\mondaishu.pdf` を開いて、次を確認してください:

- 日本語（明朝体）と数式（x² など）がきれいに出ている
- サンプルの三角形の**図**が欠けずに貼られている
- 3問目に**赤い枠（要確認）**が出ている
- コンソールに「**Overfull 警告なし**」と出ている

✅ 確認: 上記のPDFが開けて、赤枠・図・数式が表示される。

> ここでフォント関連のエラー（`metric data not found` など）が出たら、
> ステップ3の「Noto Serif CJK JP」が入っていない可能性大です。もう一度確認を。

## ステップ8. 本番実行

モックが通ったら本番です。

1. 過去問PDFを `kakomon-tool\input\` に置きます。**ファイル名の拡張子前が年度**に
   なります（例: `input\2021.pdf`, `input\2022.pdf`）。
2. APIキーが設定されていること（ステップ6）を確認。
3. 実行:

```powershell
python src\run.py
```

- 特定の年度だけ: `python src\run.py --year 2021`
- 途中まで／続きから: `work\` にキャッシュが残るので、再実行すると
  処理済みは飛ばして続きから進みます（無駄な課金を防ぎます）。

できあがりは `output\mondaishu.pdf` です。
**赤枠（要確認）の問題は、AIの自動判定なので必ずご自身で確認**してください。

## よくあるつまずき（まとめ）

| 症状 | 対処 |
|------|------|
| `python` が「見つかりません」 | ステップ2で「Add python.exe to PATH」にチェック忘れ。入れ直す |
| `Activate.ps1` で赤いエラー | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` を実行してから再度 |
| `(.venv)` が付いていない | 毎回 `.\.venv\Scripts\Activate.ps1` を実行してから使う |
| `lualatex` が「見つかりません」 | TeX Live 未インストール、または PC 再起動が必要 |
| `metric data not found` 等のフォントエラー | Noto Serif CJK JP を入れる（ステップ3） |
| `authentication` / APIキー系エラー | ステップ6のキー設定、`echo $env:ANTHROPIC_API_KEY` で確認 |
| `pip install` が失敗する | `(.venv)` が付いているか確認、ネット接続を確認 |

## Mac / Linux をお使いの場合（参考）

- ターミナルを開き、`cd` で `kakomon-tool` に移動
- 仮想環境: `python3 -m venv .venv && source .venv/bin/activate`
- 以降のコマンドは `python src/run.py --mock` のように `\` を `/` に読み替え
- APIキー: `export ANTHROPIC_API_KEY="sk-ant-..."`
- TeX（LuaLaTeX）とフォント Noto Serif CJK JP は各OSの方法で導入
