# 2. メニュー作成

## タイトル欄

「日付」：作成する日付を選択
「場所」：練習場所を選択

> 該当項目がない／変更がある場合は直接入力

---

## メニュー作成

- **カテゴリー（A列）**

W-up, Pull, Kick, Swim などのカテゴリーを選択
カテゴリーが変わる毎に一度だけ選択

> 該当項目がない場合は直接入力

- **経過時間（C列）**

各カテゴリーにかかる所要時間を累計で記載（例：15~32）
カテゴリーが変わる毎に一度だけ記載
（一番時間の要するコースを秒数切り上げ）

::: toggle 他に計上が必要なもの
- 各カテゴリー間：2分
- Easy：約5分
- Down：5分以上
:::

::: note 時間補助欄
「距離」，「本数」，「サークル」が入力されると右端に赤字で表示されます
各行ごとのメニュー対して 各コースの所要時間が表示されます

::: note コース間の時間調整
時間補助欄を範囲選択することで合計時間を確認できます【画像 右下】

![時間補助欄を範囲選択すると画面右下に合計時間が表示される](/manual/usage-time-helper.png)

「合計：44:00:00」は 計44min のメニューであることを指します
:::
:::

- **M欄（F列）**

○／Ⓗ／☆ を選択
マネージャーさんへの指示などに使ってください

- ○：読み上げ
- Ⓗ：Hardのみ読み上げ
- ☆：読み上げ & 書き出し

のように用いられることが多いです

> 該当項目がない場合は直接入力
> 記号だけでは伝えきれないことが多いので参考程度に^^

- **メニュー内容（H〜AM列）**

A／B／Cコースのメニューを それぞれ H／S／AD列から入力
「距離」→「本数」→「セット数」→「サークル」→「内容」の順に入力

::: note サークルの入力方法
サークル欄には **数字のみ** 入力してください！

例
1分15秒サークルの場合　→　115 と入力
3分サークルの場合　→　300 と入力
45秒サークルの場合　→　45 と入力

> 数字は半角で入力してください
:::

> 参考：[tips - 下線があるセル（＝操作可能セル）](/manual/tips#・自動表示されなくなった場合)
> 参考：[tips - ・セットメニューの表記](/manual/tips#・セットメニューの表記)

その他 不明な点があれば [こちら](/manual/tips) を参照してください

## 確認事項

メニューが作成できたら 以下の項目を確認してください
コメント欄の記入もお忘れなく♪

::: note
- 日付，時間，区分，場所
- マネージャーさんへの指示
- 適切なサークル，レスト
- {red}各カテゴリー所要時間【要確認】{/red}
- 各カテゴリー間に2分の休憩
- ダウンの時間が5分以上
- {red}累計所要時間【要確認】{/red}
- 総距離表示
- コメント欄
:::

# 3. メニュー出力

メニューが完成したら PDF で出力します

印刷（プリント）or エクスポート画面から以下の設定を確認してください

::: note
- 用紙サイズ：A4
- 印刷：作業中のシート
- 余白：狭い余白
- 印刷の向き：横
- 拡大縮小：シート全体を1ページに印刷
:::

::: toggle 詳細手順［Mac］
**① 出力画面へ移行**
・ツールバー→印刷

![ツールバーの印刷ボタン](/manual/usage-mac-1.png)

・ファイル→プリント

![ファイルメニューからプリントを選ぶ](/manual/usage-mac-2.png)

**② 出力設定の確認**
出力画面に移行したら、出力設定を確認してください

![プリント画面で用紙サイズ・印刷・余白・向き・拡大縮小を確認する](/manual/usage-mac-3.png)

**③ プリント／PDF出力**
プリントする場合：右下の「プリント」をタップ
　PDF出力する場合：左下の「PDF」をタップ
:::

::: toggle 詳細手順［iPhone］
**① 出力画面へ移行**
右上の「•••」をタップ

![右上の3点メニューをタップ](/manual/usage-iphone-1.png)

「エクスポート」・「印刷」をタップ

![メニューからエクスポートまたは印刷を選ぶ](/manual/usage-iphone-2.png)

**② レイアウトの確認**
出力画面に移行したら、レイアウトを確認してください

![レイアウトオプションで向き・用紙サイズ・拡大縮小を確認する](/manual/usage-iphone-3.png)

**③ プリント／PDF出力**
「次へ」をタップして保存
:::

> 時間補助欄は書き出し／印刷されない設定になっています
> もし書き出し／印刷されてしまう場合は こちら を参照してください
