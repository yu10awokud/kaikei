# 2. メニュー作成

## タイトル欄

「日付」：作成する日付を選択
「場所」：練習場所を選択

> 該当項目がない／変更がある場合は直接入力

## メニュー作成

**カテゴリー（A列）**

W-up, Pull, Kick, Swim などのカテゴリーを選択
カテゴリーが変わる毎に一度だけ選択

> 該当項目がない場合は直接入力

**経過時間（C列）**

各カテゴリーにかかる所要時間を累計で記載（例：15~32）
カテゴリーが変わる毎に一度だけ記載
（一番時間の要するコースを秒数切り上げ）

::: toggle 他に計上が必要なもの
- 各カテゴリー間：2分
- Easy：約5分
- Down：5分以上
:::

::: note 時間補助欄
「距離」，「本数」，「サークル」が入力されると右端に赤字で表示されます
各行ごとのメニュー対して 各コースの所要時間が表示されます

::: note ✨ コース間の時間調整
時間補助欄を範囲選択することで合計時間を確認できます【画像 右下】

「合計：44:00:00」は 計44min のメニューであることを指します
:::
:::

**M欄（F列）**

○／Ⓗ／☆ を選択
マネージャーさんへの指示などに使ってください

- ○：読み上げ
- Ⓗ：Hardのみ読み上げ
- ☆：読み上げ & 書き出し

のように用いられることが多いです

> 該当項目がない場合は直接入力
> 記号だけでは伝えきれないことが多いので参考程度に^^

**メニュー内容（H〜AM列）**

A／B／Cコースのメニューを それぞれ H／S／AD列から入力
「距離」→「本数」→「セット数」→「サークル」→「内容」の順に入力

::: note 🔖 サークルの入力方法
サークル欄には **数字のみ** 入力してください！

例
1分15秒サークルの場合　→　115 と入力
3分サークルの場合　→　300 と入力
45秒サークルの場合　→　45 と入力

> 数字は半角で入力してください
:::

> 参考：tips - 下線があるセル（＝操作可能セル）
> 参考：tips - ・セットメニューの表記

その他 不明な点があれば こちら を参照してください

## 確認事項

メニューが作成できたら 以下の項目を確認してください
コメント欄の記入もお忘れなく♪

- 日付，時間，区分，場所
- マネージャーさんへの指示
- 適切なサークル，レスト
- {red}各カテゴリー所要時間【要確認】{/red}
- 各カテゴリー間に2分の休憩
- ダウンの時間が5分以上
- {red}累計所要時間【要確認】{/red}
- 総距離表示
- コメント欄

# 3. メニュー出力

メニューが完成したら PDF で出力します

印刷（プリント）or エクスポート画面から以下の設定を確認してください

- 用紙サイズ：A4
- 印刷：作業中のシート
- 余白：狭い余白
- 印刷の向き：横
- 拡大縮小：シート全体を1ページに印刷
