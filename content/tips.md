## ・自動表示されなくなった場合

自動表示されるセルには そのための関数が書かれています
関数セルに操作を行うと、関数が消え、自動表示されなくなります

メニュー変更時、範囲選択で一括消去すると必発します！

::: note
下線があるセル（＝{red}操作可能{/red}セル）
関数がないため 文字入力・消去などの操作が可能
　実際に セル内に関数はありません【画像 Q6】
　例）Q列【画像】，A列，C列，F列…

下線がないセル（＝{red}操作禁止{/red}セル）
関数があるため 原則操作禁止
　実際に セル内に on を自動表示するための関数があります【画像 N6】
　例）N列【画像】，B列，D列，E列…

> ※ 余白のために下線がない列もあります
:::

::: note **対処方法**
- 範囲選択で一括消去しない

→ 下線がある列ごとに範囲選択で消去

- 一括消去後、動作正常な列から機能を復元する

→ 操作方法：[② 自動表示機能をつける](#・メニュー欄行を追加したい場合)
:::

## ・セットメニューの表記

見やすさのために できるだけ以下の表記方法で統一してください

::: note
例）50×2／100×1 を 2セット するとき

**① メニューを入力する**
メニューを入力（全ての行に対してセット数を入力！）
　このとき各コース分の同時作成は非推奨（最後にコピペ！）

**② 罫線を引く**
× が表示されているセルに左罫線を引く（or 本数を入力したセルに右罫線）

**③ フォントを白にする**
一番下以外の「×(セット数)」部分の{red}フォントを白色{/red}にして、印刷を免れてください！
　⚠︎塗りつぶしではありません！　⚠︎文字消去ではありません！

**④ 各コースにコピペする**
「距離〜内容」部分を範囲選択して 各コースにコピペして完成です♪
:::

## ・時間補助欄が書き出し／印刷される場合

Ver.6以降では AS〜AU列 に時間補助欄が追加されています
基本的には書き出し／印刷されません

::: toggle 機能
（内容は追って追加します）
:::

::: note **対処方法**
時間補助欄を除くメニュー部分を**範囲選択**してから出力画面へ移行し、
次のような出力設定を確認してください

- 用紙サイズ：A4
- {red}印刷：選択範囲{/red}
- 余白：狭い余白
- 印刷の向き：横
- 拡大縮小：シート全体を１ページに印刷

それ以降は[マニュアル](/manual/usage)に記載されている流れに沿って書き出し／印刷してください
:::

## ・メニュー欄（行）を追加したい場合

::: note **対処方法**
**① 列を挿入する**
メニューとコメント欄の間の行【画像 28行目】を選択する
　（追加したい行の１つ下の行を選択する）

行を挿入する

このとき、選択した行の１つ上に新しい行が追加されます

**② 自動表示機能をつける**
メニュー欄のいずれかの行【画像 25行目】をコピーする
　（カテゴリー間などのメニューを記載していない行に限る）
　新しく追加した行【画像 28行目】にペーストする

これで、正しく × や on などが自動で表示されるようになります【画像 28行目】

> オートフィル機能での操作もオススメです^^
:::
