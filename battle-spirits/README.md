# Battle Spirits オンライン・プレイマット（GAS）

このフォルダは Google Apps Script 製の Battle Spirits プレイマットです。
（このリポジトリのルートにある「収入管理ツール」とは別物で、上書きしないよう
`battle-spirits/` に置いています。GAS エディタには下記3ファイルを貼り付けてください。）

- `Code.gs` … サーバー側（スプレッドシート／Drive 画像／ゲーム状態）
- `Index.html` … クライアント（盤面UI）
- `appsscript.json` … マニフェスト

---

## 重要：画像フォルダの構成（変更点）

カード画像は Google Drive の **`Battle Spirits Images`** フォルダの中に、
**カードIDの前半（最初の `-` より前）の名前のサブフォルダ**を作って入れてください。

```
Battle Spirits Images/
├── BS65/
│   ├── BS65-001.png
│   ├── BS65-001_b.png     ← 転醒後（_b）も同じ前半フォルダに入れる
│   └── BS65-014.webp
├── CB28/
│   └── CB28-013.png
└── back/
    └── back.png           ← カード裏面（このフォルダには1枚だけ）
```

- ファイル名は **カードID + 拡張子**（`.png` `.webp` `.jpg` …いずれも可）。
- 万一サブフォルダ名が前半と一致しなくても、`Battle Spirits Images` 配下を
  全走査して同名ファイルを探す**安全網**を入れてあります（ただし遅くなるので、
  基本は前半フォルダに入れてください）。
- 画像は「必要なときに必要な分だけ」読み込みます（後述）。

## 重要：契約カードの指定

スプレッドシートに自動生成される **`Contracts` シート**の A 列に、契約カードの
**カードID**を1行ずつ列挙してください（ヘッダ行 `cardId` の下から）。

開始処理では、デッキに契約カードがあれば **契約カード1枚 + 契約以外からランダム3枚**
を初期手札にします（契約が無ければ通常どおり4枚ドロー）。

## 転醒（_b）

場のカードを右クリック →「転醒する／取り消す」で、カードIDの末尾に `_b` を
付け外しします。`BS65-001` ⇄ `BS65-001_b`。`_b` 画像も上記の前半フォルダに置けば、
転醒したタイミングで自動的に読み込まれます。

## 画像の読み込み（高速化）

### 仕組み（公開しなくても速い）

- **通常モード（base64・既定）**：サーバーが Drive の**サムネイルを並列（fetchAll）**で取得して
  返します。**フォルダを公開する必要はありません**。1枚ずつではなく一気に取得し、画像も
  小さい（既定 w500）ので速くなります。
  - ※ 初回は再認可（外部リクエスト／Drive の権限）が必要です。デプロイ後の初回実行で承認してください。
- **高速モード（CDN・任意）**：フォルダを「リンクを知っている全員＝閲覧者」に共有すると、
  ファイルIDだけ返してブラウザが Google CDN から直接取得します（最速）。設定タブのボタン、
  または Drive で共有。共有しない場合は通常モードで動きます。
- サムネを1枚だけキャッシュして、盤面でも「詳細を見る」でも同じ画像を使い回します
  （**サムネ用と詳細用で二重に読み込みません**）。

### ゲーム開始の流れ（界放）

1. 両者がデッキを入力 → **「ゲームスタート」**を押す（席A・席Bそれぞれ）。
2. 2人がそろうと「**ゲートオープン！ 界放！**」の読み込み画面（％ゲージ）が出ます。
3. その間に**両者のデッキのカード＋実在する転醒先（_b）**をまとめて先読みします。
4. 読み込み後、自動で配布（シャッフル・4枚ドロー・契約処理・コア準備）して対戦開始。

→ 対戦中はキャッシュ済みなので画像は即表示されます。

### 読み込むタイミング

全カードを一括では読み込みません。読み込むのは次の場面だけです。

- **裏面**（`back/back.png`）… 起動時に1回。
- **保存済みデッキのサムネイル**（先頭カード）… 「デッキ」タブを開いたとき。
- **デッキレシピの中身**… 各デッキの「表示」を押したときに初めて。
- **対戦中に見えているカード**… 盤面に出た／公開された／手札にある等、表示が必要に
  なった分だけまとめて取得（相手の見えているカードも含む）。
- **開始処理**を押すと、そのデッキの画像を先読みし、前のデッキにしか無かった画像の
  キャッシュは破棄します（Drive のファイルは消しません）。

> 相手の山札・手札（非公開領域）の画像は、情報秘匿のため事前読み込みしません。
> 場に出る等して公開された瞬間にまとめて読み込みます。

## 主な操作

- **煌臨**：手札のカードをクリック →「煌臨する」→ 場の対象を選択。重ねたカードが前面、
  下のカードは名前だけが見えます。コアは前面に集約。
- **合体（ブレイヴ）**：場のカードをクリック →「合体する」→ 重ねる先を選択。
  重ねられたカードの画像の右半分・上2/3が隠れます。
- 疲労／重疲労にすると、重ねたカードごと一体で回転します。場のカードを動かすと
  重ねたカードも一緒に動きます。
- **コア移動**：初期値は「リザーブ → トラッシュ」。同名カードが複数あるときは
  2枚目以降に ②③④… の番号が付きます。

## デッキの初期化（リセット）

「設定」タブからリセットできます。`Config` シートの `resetPin`（初期値 `0000`）が必要です。
